# Componentes de terceiros

## Google Maps Scraper

Projeto: `gosom/google-maps-scraper`

```text
https://github.com/gosom/google-maps-scraper
```

Licença: MIT segundo o repositório consultado na preparação desta versão.

O código do projeto externo não está incorporado ao Achilles Command. A integração chama a imagem Docker `gosom/google-maps-scraper:latest` em tempo de execução.

## Leaflet

A interface de Prospecção usa Leaflet 1.9.4 carregado por CDN para exibir os pontos geográficos retornados pelo scraper.

```text
https://leafletjs.com/
```

## Observação

Projetos externos podem evoluir. Antes de redistribuir, hospedar para terceiros ou alterar a forma de integração, confira suas versões e licenças atuais.
